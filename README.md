# Chicken Game

친구 2~4명이 치킨집을 운영해 누적 매출 10,000,000원을 달성하는 Unity 1인칭 협동 게임입니다.

- 엔진: Unity 6000.5.7f1
- 렌더 파이프라인: URP 17.5.0
- 플랫폼: Windows 64-bit 스탠드얼론
- 시점: 1인칭 전용
- 멀티플레이: Netcode for GameObjects 2.13.2 (호스트 1 + 접속 3인까지 색이 구분됩니다)

## 게임 흐름

1. 타이틀에서 혼자 시작, 호스트, 접속 중 하나를 고릅니다.
2. `냉장고 → 튀김기 → (양념대) → 포장대 → 계산대 / 배달대` 순서로 치킨을 만듭니다.
3. 손님은 문으로 걸어 들어와 줄을 서고, 인내심이 다하면 화를 내며 나갑니다.
4. 번 돈은 업그레이드 데스크에서 가게에 다시 투자합니다.
5. 하루(600초)가 끝나면 결산 화면이 뜨고 자동 저장됩니다.
6. 누적 매출 1,000만 원을 넘기면 승리, 평판이 0이 되면 폐업입니다.

## 조작

한 화면에 한 사람의 시점만 담기므로, 한 대의 PC 에서는 혼자 합니다.
여럿이 하려면 호스트로 열고 친구가 접속합니다 (최대 4인).

| 동작 | 키보드 · 마우스 | 게임패드 |
| --- | --- | --- |
| 이동 | `WASD` / 방향키 | 왼쪽 스틱 |
| 시점 | 마우스 | 오른쪽 스틱 |
| 점프 | `SPACE` | `LB` |
| 상호작용 · 줍기 · 소화 | `E` | `A` (South) |
| 내려놓기 | `F` | `X` (West) |
| 소스 전환 (내 선택) | `Q` | `Y` (North) |
| 업그레이드 | `1`~`5` | D-Pad 오른쪽으로 슬롯 선택, `B` 로 구매 |
| 마우스 감도 | `[` `]` | — |

공용 키: `SPACE` 결산·결과 넘기기, `ESC` 일시정지, 일시정지 중 `R` 처음부터,
폐업 화면에서 `R` 재기.

## 시점

1인칭 전용입니다. 마우스로 둘러보고 이동은 보는 방향 기준이며, 몸도 늘 보는 쪽을 향합니다.
걸으면 시야가 출렁이고, 사고가 나면 화면이 흔들립니다. 감도는 `[` `]` 로 바로 조절되고 저장됩니다.

**조준선이 곧 손입니다.** 화면 중앙 점이 스테이션을 물면 점이 노랗게 바뀌고 아래에 할 일이
뜹니다. 겨냥이 빗나가면 예전처럼 가까운 스테이션으로 떨어지므로, 급할 때 조준을 강요하지는
않습니다. 들고 있는 것은 화면 오른쪽 아래에 실제로 보이고, 하단 중앙에도 글로 뜹니다.

## 시스템

- **캐릭터** 플레이어와 손님은 파티 캐릭터 모델로 나오고 걸으면 달리는 동작이 붙습니다.
  주방 사람은 셰프 모자를, 손님은 파티 모자와 중절모를 섞어 씁니다. 1인칭이라 내 몸은 보이지 않습니다.
- **가게 소품** 냉장고·양념대·포장대는 가구 모델이 블록을 대신하고, 계산대·배달대·업그레이드는
  블록을 카운터로 남긴 채 금전등록기와 스탠드를 위에 올립니다. 치킨은 실제 치킨 모델이고
  포장하면 상자가 씌워집니다. 배달 스쿠터도 모델로 나옵니다.
  튀김기·쓰레기통·소화기는 급할 때 눈에 띄어야 해서 색이 분명한 블록으로 남겼습니다.
- **스테이션 이름표** 각 블록 위에 이름이 떠 있고, 조준하면 지금 할 일을 알려줍니다.
- **손님 주문 표시** 손님 머리 위에 원하는 메뉴와 남은 수량, 남은 시간이 뜹니다.
- **손님 성격 4종** 급함(값 +45%, 인내심 짧음), 느긋(인내심 길고 값 -15%), 단골(값 2배, 놓치면 평판 2배 손해), 보통. 기다리다 지치면 발을 구르고, 한 명이 화내며 나가면 남은 손님들도 조급해집니다.
- **최고 기록** 타이틀 화면에 최고 DAY 와 하루 최고 매출이 남습니다.
- **소리** 효과음과 배경 음악을 런타임에 합성합니다. 주문이 밀리면 음악이 빨라집니다.
- **메뉴 3종** 후라이드(18,000) / 양념(21,000) / 간장(20,000). DAY 가 오르면 차례로 해금됩니다.
- **배달** 주소마다 거리와 배달비가 다르고, 스쿠터가 왕복하는 동안 기다려야 합니다.
- **업그레이드 5종** 고성능 튀김기, 튀김기 증설(2대 → 최대 4대), 미끄럼방지 신발, 스쿠터 튜닝, 전단지 마케팅.
- **랜덤 이벤트 6종** 러시아워, 배달앱 프로모션, 단체 주문, 진상 손님, 정전, 위생 점검.
- **주방 사고** 기름 웅덩이에 미끄러지면 들고 있던 것을 놓치고, 탄 치킨을 튀김기에 방치하면 불이 납니다. 소화기 스탠드와 쓰레기통으로 수습합니다.
- **평판** 좋으면 손님이 더 자주 오고 팁이 붙습니다. 나쁘면 발길이 뜸해집니다. 0 이 되면 폐업입니다.
- **콤보** 연속 성공마다 정산액이 10%씩 올라 최대 2배까지 붙습니다.
- **세트 주문** DAY 3 부터 두 마리, DAY 5 부터 세 마리까지 시킵니다. 수량을 다 채워야 손님이 갑니다.
- **난이도 곡선** DAY 마다 단가 +40%, 주문 간격 -8%, 손님 인내심 -5%.

## 실행

Unity Hub에서 이 폴더를 Unity 6000.5.7f1로 연 뒤:

1. `Chicken Game > Build MVP Scene` 을 한 번 실행합니다.
2. `Chicken Game > Build Network Prefab` 으로 네트워크 프리팹을 굽습니다.
3. `Assets/Scenes/ChickenGame.unity` 를 열고 Play 를 누릅니다.

빌드는 메뉴 `Chicken Game > Build Windows Player` 또는 배치 모드로 만듭니다.

```
Unity.exe -batchmode -quit -nographics -projectPath . \
  -executeMethod ChickenGameBuilder.BuildFromCommandLine -buildOutput Builds/ChickenGame.exe
```

## 자동 검증

빌드가 실제로 도는지 사람 손 없이 확인합니다. 냉장고 → 튀김기 → 익음 → 탐 → 폐기와
양념 → 포장까지 한 바퀴 돌려보고, 항목별 PASS/FAIL 을 로그로 남긴 뒤 종료 코드로 알려줍니다.

```
ChickenGame.exe -mode local -selftest -logFile selftest.log
ChickenGame.exe -mode host -selftest -verbose -logFile selftest-host.log
```

`-daylength 40` 으로 하루를 줄이고, `-startday 6` 으로 후반 DAY 상태를 바로 볼 수 있습니다.
`-autoday` 는 결산 화면을 자동으로 넘겨 무인 장시간 테스트를 돌릴 때 쓰고,
`-verbose` 는 스폰과 네트워크 진단 로그를 켭니다.

봇이 주방 파이프라인을 끝까지 돌려보는 측정도 있습니다. 다만 이 봇은 사람처럼 플레이하지
못하므로 (튀김이 끝날 때까지 서서 기다리고, 주문을 겹쳐 돌리지 못합니다) 난이도 기준이 아니라
**서투른 플레이의 하한선**으로만 읽습니다. 자세한 내용과 수치는 `BALANCE.md` 에 있습니다.

```
ChickenGame.exe -mode local -balancetest 5 -bots 2 -daylength 240 -logFile balance.log
```

## 멀티플레이

호스트가 먼저 열고, 같은 네트워크의 친구가 호스트 IP로 접속합니다. 기본 포트는 `7777` 입니다.

한 화면에 시점이 하나뿐이므로, 여럿이 하려면 각자 자기 PC 에서 접속합니다.

- 게임 안에서: 타이틀 화면에서 `H`(호스트) 또는 `J`(주소 입력 후 접속).
  `J` 를 누르면 주소 입력 칸이 뜹니다. 숫자와 `.` 만 받고 `ENTER` 로 접속, `ESC` 로 취소합니다.
  마지막에 쓴 주소를 기억하므로 다음 판은 `J` `ENTER` 두 번이면 됩니다.
- 실행 인자로 바로 시작:

```
ChickenGame.exe -mode host
ChickenGame.exe -mode client -address 192.168.0.5
ChickenGame.exe -mode local
```

주방 시뮬레이션은 호스트가 계산합니다. 접속한 플레이어의 상호작용은 호스트로 전달되고,
매출·DAY·평판·주문 목록과 손님, 치킨은 모두에게 동기화됩니다.

## 알려진 제약

- 일시정지는 각자 로컬 화면입니다. 결산 화면은 모두에게 함께 뜨고, 호스트가 SPACE 로 넘깁니다.
- 접속은 같은 네트워크(LAN) 기준입니다. 릴레이 서비스는 붙이지 않았습니다.

## 개발 기록

`DAY 07` 단일 플레이 루프 → `DAY 08` 네트워크 조사(보류) → `DAY 09` 메뉴/양념 →
`DAY 10` 손님 AI → `DAY 11` 배달 → `DAY 12` 업그레이드 → `DAY 13` 랜덤 이벤트 →
`DAY 14` 주방 사고 → `DAY 15` 결산·저장 + 1~14 검토 → `DAY 16` 사운드/이펙트 →
`DAY 17` 게임 흐름과 승패 → `DAY 18` 난이도 밸런싱 → `DAY 19` 멀티플레이 복귀 →
`DAY 20` 서버 권한 주방 + 최적화 → `DAY 21` 최종 빌드 →
`DAY 22` 게임패드·4인 → `DAY 23` 사고 연출 동기화 → `DAY 24` 셀프테스트 →
`DAY 25` 검증 확대 → `DAY 26` 스테이션 이름표 → `DAY 27` 코드 분리 →
`DAY 28` 세트 주문 → `DAY 29` 손님 주문 표시 → `DAY 30` 음악·정전 →
`DAY 31` 전원 담는 카메라 → `DAY 32` 할당 정리 → `DAY 33` 밸런스 측정 →
`DAY 34` 측정으로 찾은 결함 수정 → `DAY 35` 걷는 봇 → `DAY 36` 손님 성격 →
`DAY 37` 타이틀에서 주소 입력 → `DAY 38` 폐업 후 재기 → `DAY 39` 1인칭 시점 추가 →
`DAY 40` 1인칭 전용 전환, URP 전환과 에셋 적용.

## 에셋

캐릭터·가구·치킨·스쿠터는 외부 에셋 팩을 씁니다. 팩이 모두 URP 로 만들어져 있어서
프로젝트도 URP 로 갑니다 - 빌트인 파이프라인에서는 재질이 전부 깨져 자홍색으로 나옵니다.

런타임에 불러오는 프리팹은 `Assets/Resources/Props/` 에 모아 두었습니다.
팩을 지워도 게임은 돌아갑니다. 모델을 못 찾으면 예전의 색 블록과 캡슐로 그려집니다.
