# Chicken Game

친구 2~4명이 치킨집을 운영해 누적 매출 10,000,000원을 달성하는 Unity 협동 게임입니다.

## DAY 7 MVP

- Unity 6.0.5f1
- 런타임에 생성되는 작은 치킨집 테스트 공간
- WASD/방향키 플레이어 이동
- 냉장고, 튀김기, 포장대, 계산대 블록
- `RAW -> FRYING -> COOKED/BURNT -> PACKAGED` 음식 상태
- 12초 간격 손님 주문 및 45초 제한 시간
- 주문 성공/실패, 빠른 처리 보너스, 누적 매출
- 10분 DAY 진행과 주문/성공/실패/탄 치킨 통계
- 실제 Windows Standalone 빌드 검증

## 실행

1. Unity Hub에서 이 폴더를 Unity 6000.5.7f1로 엽니다.
2. `Chicken Game > Build MVP Scene` 메뉴를 한 번 실행합니다.
3. `Assets/Scenes/ChickenGame.unity`를 열고 Play를 누릅니다.
4. `WASD` 또는 방향키로 이동하고 `E`로 상호작용합니다.

## 첫 플레이 루프

1. 냉장고에서 생닭을 듭니다.
2. 튀김기에 넣고 5초 뒤 다시 `E`로 꺼냅니다. 8초를 넘기면 탑니다.
3. 포장대에서 포장합니다.
4. 계산대에서 주문을 완료하고 매출을 올립니다.
5. 주문 제한 시간과 통계를 확인하며 반복합니다.

다음 단계는 배달, 업그레이드, 랜덤 이벤트, 물리 사고, 그리고 멀티플레이입니다.
