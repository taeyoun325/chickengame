# Chicken Game

친구 2~4명이 치킨집을 운영해 누적 매출 10,000,000원을 달성하는 Unity 협동 게임입니다.

## 현재 상태 (DAY 15)

- Unity 6000.5.7f1
- 런타임에 생성되는 치킨집 (조리 라인 뒷줄 / 손님 카운터 앞줄)
- 로컬 2인 협동: P1 `WASD`, P2 `IJKL`, 공통 `E` 상호작용
- 메뉴 3종: 후라이드 / 양념 / 간장 (DAY 가 오르면 순서대로 해금)
- `생닭 → 튀김 → (양념) → 포장 → 계산대 / 배달대` 조리 흐름
- 문으로 걸어 들어와 줄을 서고, 인내심이 다하면 화내며 나가는 손님
- 배달 주문: 주소별 거리 · 배달비, 스쿠터가 나갔다 돌아오는 왕복 시간
- 업그레이드 5종: 튀김기 성능/증설, 이동 속도, 스쿠터 튜닝, 마케팅
- 랜덤 이벤트 6종: 러시아워, 배달앱 프로모션, 단체 주문, 진상 손님, 정전, 위생 점검
- 주방 사고: 기름 웅덩이 미끄러짐, 바닥에 떨어진 치킨, 튀김기 화재와 소화기
- 하루(600초) 종료 시 결산 화면과 자동 저장 / 이어하기

## 조작

| 키 | 동작 |
| --- | --- |
| `WASD` / 방향키 | 플레이어 1 이동 |
| `IJKL` | 플레이어 2 이동 |
| `E` | 스테이션 상호작용, 줍기, 불 끄기 |
| `F` | 들고 있는 것 내려놓기 (바닥에 닿으면 못 씀) |
| `Q` | 양념대 소스 전환 (양념 ↔ 간장) |
| `1`~`5` | 업그레이드 데스크 앞에서 업그레이드 구매 |
| `SPACE` | 결산 화면에서 다음 DAY 시작 |

## 실행

1. Unity Hub에서 이 폴더를 Unity 6000.5.7f1로 엽니다.
2. `Chicken Game > Build MVP Scene` 메뉴를 한 번 실행합니다.
3. `Assets/Scenes/ChickenGame.unity`를 열고 Play를 누릅니다.

Windows 빌드는 `Chicken Game > Build Windows Player` 메뉴 또는 배치 모드로 만듭니다.

```
Unity.exe -batchmode -quit -nographics -projectPath . \
  -executeMethod ChickenGameBuilder.BuildFromCommandLine -buildOutput Builds/ChickenGame.exe
```

## 첫 플레이 루프

1. 냉장고에서 생닭을 듭니다.
2. 튀김기에 넣고 5초 뒤 다시 `E`로 꺼냅니다. 8초를 넘기면 탑니다.
3. 주문이 양념/간장이면 양념대에서 `Q`로 소스를 맞추고 `E`로 바릅니다.
4. 포장대에서 포장하고 계산대(또는 배달대)로 가져갑니다.
5. 번 돈으로 업그레이드 데스크에서 가게를 키웁니다.
